**性质：探索性分析，分析规则冻结 —— 不是对未见数据的预注册。**

本文件固定"算什么、怎么呈现"，其 sha256 记入每次 `results/run_00X/manifest.json`。
撰写本文件之前，首轮/二轮消融的 mAP / AP75 / APs / AR@100 汇总与背景误检分档已被查看，
因此本文件**不具备盲态预注册的验证力**：任何基于阈值的"通过／不通过"都不构成科学判据。
变更规则须另建新文件与新 run，不改本文件。

其判据已按 2026-09-29 的评审意见撤除，见下节。

## 0. 相对 v1 撤除的两套判据

**（一）撤除 v1 §5「共同瓶颈」五条判据及其通过／不通过裁定。**

理由：

- `bkg` / `dupe` 统计的是**预测框**，`miss` / `imprecise` 统计的是 **GT**，两者单位不同，
  **不能按数量排名推断对 AP 的影响**；"背景框最多"不等于"影响最大"。
- 背景框多、逐图 Pearson 高（0.97 级）只支持「**当前导出结果中持续存在的共同错误模式**」，
  不支持对重要性的排序，也不支持"唯一瓶颈"的表述。
- v1 的 top-10 贡献 < 0.4 是**人为阈值**；`imprecise` 的 0.402 仅擦线越过，
  **不足以排除其重要性**。以擦线阈值排除一个错误类别不成立。

结果：本分析**不指定共同瓶颈**，只输出描述统计。

**（二）撤除 v1 §6「同一现象（反向）／两个不同现象／功效不足」机制裁定。**

理由：

- 两个特征的 `p > 0.05`、较小的 Cliff's δ、以及翻转数量比例相近，
  **不能识别共同机制**；把结论写成"与……一致"同样不解决问题。
- 这些量只应作为**描述统计**呈现。

结果：机制结论字段一律为固定的「**现有证据无法裁定**」。

## 2. 术语更正（必须遵守）

- 由逐 GT `best_iou_any` 定义、跨越 0.5 / 0.75 的变化称「**几何覆盖翻转**」
  （geometric coverage flip），**不得直接当作 AP75 的解释**。
- AP75 的解释必须另列「**COCO 匹配变化**」：由 COCOeval 自身的逐图贪心匹配给出
  （`maxDet=100`、`areaRng='all'`、IoU 档 0.5 / 0.75），与几何覆盖口径并列、不混用。
- 逐 GT 的"是否被覆盖"用 `best_iou_any`；"被分配的框的质量"用 `matched_pred_iou`。两处不得互换。
- 两种 IoU 实现（冻结脚本手写 `iou()` 与 pycocotools 自有实现）的差异**必须实测并如实报出**，
  不得假定一致；两个口径的结果并列呈现，不合并。

## 3. 描述统计清单（均无裁定）

- **Part A**：`legacy`/`coverage` 各模式计数与占比（**并列标明计数单位：预测框 / GT**）、
  逐图向量两两 Pearson、三折 top-quartile 交集及其随机期望、top-10 图贡献占比、bkg 分层占比。
- **Part A 附加**：预测侧联合统计 `预测框面积档 × 分数档 × 该预测对同图所有 GT 的最大 IoU 档`
  的计数，并**并列该格的 TP / 背景误检 / 重复**。目的：直接给出"高分 × 小框"的**交集**，
  不靠"小框占比高"与"高分占比高"两个边际比例推断。
- **Part B**：配对翻转计数、特征描述统计（中位数、q1/q3、中位数差的置换检验 p、Cliff's δ、
  翻转数量比值）。**只作描述**，不作机制推断。
- **Part B 附加**：COCO 匹配变化（新匹配 / 丢失匹配 / 保持 / 从未匹配）逐 GT 对照，
  记录状态变化 GT 的匹配框分数、被分配框是否改变、以及该 GT 在 IoU ≥ 阈值的预测条数
  （用于"匹配与分数排序"的对照）；并输出各 run 在 IoU 0.75 / 0.50 的 101 点 PR 曲线。

## 4. 边界与非目标

- 不训练、不重跑推理；只读六组导出预测与各自 `test.json`。
- **不据本测试集调整任何 score / NMS 阈值**；不叠加 M2 / FG。
- 成因字段（未产生好框 / 好框被分数过滤 / 好框被 NMS 抑制）**一律记「未知」**，
  不由低重复率、低覆盖率或高分背景框数量倒推。候选级归因属阶段二，本轮不执行。
- 本轮**不产生新的验证证据**：该 232 图此前已参与 AP75 讨论，本轮只输出诊断线索。
  后续独立留出必须是此前未参与选择的 SAR 图像/场景；仅更换 3-shot 标注折或随机种子、
  但仍评价同一 232 图，**不构成新的独立测试集**。
- `ShipRSImageNet` 按 `audit_softnms_cr4o9epx/CORRECTION.md` 实为光学遥感、非 SAR，
  其"独立 SAR"表述已撤回，ShipRSImageNet test 保持封存。
