# 更正说明（2026-09-11）

## 1. 更正事项

本轮 A/B 消融所用“开发集”**ShipRSImageNet 是光学遥感船舶数据集，不是 SAR**。
`.bmp` 只是文件格式，不代表传感器类型；官方将其定义为高分辨率光学遥感船舶数据集。

因此，前版交付物中“独立 SAR 集 / 3435 bmp SAR”的表述**全部撤回**，改为“外部光学集 / 光学遥感”。

## 4. 结果判断（不判失败，也不判 SAR 有效）

- Soft-NMS（Linear, iou=0.5, min_score=0.05, offset=0）在光学开发集上 AP +0.0012~0.0017、
  AR@100 +0.028~0.030；SSDD 上 AP +0.0029~0.0059、AR@100 +0.032~0.045。方向一致但幅度小。
- 六个模型—数据组合**不是六次独立随机重复**，不能仅凭全部为正宣称统计稳定有效。
- 报告中的耗时是**从 CPU 候选缓存开始的回放耗时**，不能据此宣称 Soft-NMS 在真实 GPU 推理中更快。
